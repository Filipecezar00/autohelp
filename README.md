## Projeto
O AutoHelp busca auxiliar usuários a encontrar mecanicos, guinchos e borracheiros proximos de sua região, de forma ágil. Possibilitando entrar em contato em tempo real com o prestador e criar solicitações para serviços de emergência.O sistema permite acessar um mapa no qual exibe os prestadores e suas informações.
![Demonstração do sistema]

**Backend:**Node.js - MySql

## Execute Localmente
* Clone o repositório : `git clone https://github.com/Filipecezar00/autohelp.git`
* Acesse a pasta e instale as dependências:`npm install`
* Configure as variáveis de ambiente criando um `.env` na raiz do projeto (adicione a chave `VITE_API_URL=http://localhost:3001`).
* Inicie o servidor local digitando: `npm run dev`
